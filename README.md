# isometric

Library for rendering isomtric visuals for haxe flixel games

## required
 - [haxe](https://haxe.org/)
 - [lime](https://lime.openfl.org/)

## setup
```sh
haxelib install flixel
haxelib git --always flixelutils https://github.com/bitDecayGames/flixel-utils
```

## run demo
```sh
lime test html5
```
